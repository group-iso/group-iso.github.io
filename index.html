An Overview of Human–AI Interaction Process

  • We asked ChatGPT to work on tensor isomorphism for low slice rank tensors. Such tensors were known to be a bottleneck case of Xiaorui Sun's STOC '23 breakthrough. Xiaorui also explicitly discussed this at a Shonan Meeting in late April in response to a question from James B. Wilson. As a result, ChatGPT produced a note presenting a faster Las Vegas algorithm for tensors of low analytic rank over finite fields of odd characteristic, with expected running time \(q^{O(n+a^2)}\). [PDF]
  • Along with the above note, we gave ChatGPT our FOCS '24 paper, and provided the following suggestion: improving the second enumeration stage alone would not improve the overall running time, because the first stage remained dominant. We requested ChatGPT to take this observation into consideration, to develop a new worst-case algorithm for the same three-tensor isomorphism problem with running time \(q^{O(n^c)}\) for some fixed \(c<3/2\). The resulting note presents a deterministic algorithm over finite fields of odd characteristic with running time \(q^{O(n^{4/3}\log(n+2))}\). [PDF]
  • In relation to the goal of a \(q^{O(n)}\)-time algorithm, we provided the following advice to ChatGPT: the underlying matrix-group structures should be computable within this time bound. This led to a note presenting a deterministic \(q^{\widetilde{O}(n)}\)-time algorithm for three-tensor isomorphism over finite fields of odd characteristic, by which point the work had moved entirely away from low analytic rank. The stronger \(q^{O(n)}\) target remained unresolved, and progress toward it stalled for an extended period despite continued attempts. [PDF]
  • We noticed that an earlier improvement from \(q^{O(n^{4/3}\log(n+2))}\) to \(q^{O(n^{4/3})}\) was due to a revised potential function and selection rule. We therefore asked ChatGPT whether a similar idea could remove the logarithmic overhead from the \(q^{O(n\log(n+2))}\)-time algorithm and yield a \(q^{O(n)}\) bound. This guidance led to further work on a global amortization argument and recursive algorithm, eventually resulting in a note presenting a deterministic \(q^{O(n)}\)-time algorithm for three-tensor isomorphism over finite fields of odd characteristic. [PDF]
  • We provided a FOCS '26 paper (Grochow--Ivanyos--Qiao--Sun, after it appeared on arXiv) as a reference and asked ChatGPT to improve the worst-case running time for quadratic-form tuple isometry in characteristic two. We then asked whether this line of work could be extended to three-tensor isomorphism in characteristic two. This guidance led to a note presenting a deterministic \(q^{O(n)}\)-time algorithm for three-tensor isomorphism over finite fields of characteristic two. [PDF]
  • The connection between 3TI over fields of characteristic 2 and group isomorphism is trickier than the odd counterpart. Still, given the AI-generated note, the 2-groups of Frattini class 2 should be within reach, so we asked GPT to work on that, and GPT gave a positive result. We then requested GPT to consider more general group classes, including p-groups and groups with non-trivial solvable radicals. During this process, ChatGPT identified the group extension and cohomology approach. This sustained guidance culminated in a note proposing a deterministic algorithm for arbitrary finite groups given by multiplication tables, with running time polynomial in the group order, drawing on the degree-3 quotient tensor module transporter (that appears in our current draft), group-extension methods, and cohomology. [PDF]
